# Al-Warraq: Academic Book Recommendation and Search Web App

A student project for finding and recommending academic books using **TF-IDF** and **cosine similarity**. The application combines content-based search with a Flask web interface and an optional AI chatbot.

## Project highlights

- **Recommendation and search:** TF-IDF vectorization, cosine similarity, query preprocessing, and book ranking.
- **Personalization:** Saved favorites and user interests, with accounts managed through Flask and SQLAlchemy.
- **AI chatbot:** Groq integration with SambaNova as a fallback (requires separate API keys).
- **Evaluation:** Scripts and stored evaluation outputs for search relevance, response times, concurrency, and chatbot tests.
- **Visualization:** Charts showing evaluation metrics in `report_charts/`.

## Technology stack

Python · Flask · Flask-SQLAlchemy · pandas · NumPy · scikit-learn · SymSpell · Groq API · SambaNova API · HTML/CSS/JavaScript

## Repository structure

```text
app.py                  # Flask application, recommendation logic, chatbot, and routes

evaluate.py             # Search and performance evaluation
charts.py               # Produces evaluation charts

report_charts/          # Evaluation figures

```

## Run locally

1. Use **Python 3.12** and create a virtual environment.

   ```bash
   python -m venv .venv
   ```

   Activate it in Windows PowerShell:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

   Or on macOS/Linux:

   ```bash
   source .venv/bin/activate
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Copy `.env.example` to `.env` and fill in your own `SECRET_KEY`. API keys are optional for the chatbot, but required to enable those services.

4. Put an appropriately licensed copy of your book dataset at:

   ```text
   dataset/AlWarraq_Final_Version.csv
   ```

   The training script expects columns including `context`, `title`, `author`, `category`, and `description`.

5. Generate the recommendation artifacts:

   ```bash
   python train_model.py
   ```

6. Start the Flask application locally:

   ```bash
   python app.py
   ```

   Open `http://127.0.0.1:5000`.

> **Note:** The original source project's book dataset and pre-trained `.pkl` models were deliberately excluded from this public-sharing package. The application needs a compatible dataset and locally generated model files to function fully. The original source also runs Flask in debug mode; this is suitable only for local development, not public deployment.

## Evaluation and charts

The `report_charts/` directory contains figures created by the project's evaluation tooling. Saved evaluation CSV files are also included for inspection.

## Data and security notes

- **Never commit** `.env`, API keys, session data, local databases, or Git history copied from another folder.
- Check dataset licensing and the permission to redistribute book descriptions before publishing your data.
- API keys must be stored in environment variables, not source code or screenshots.
- The chatbot's safeguards are basic academic-project protections, **not** a claim of production-grade security.
